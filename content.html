Introduction

Midi2Text (also MidiToText, or MF2T) is a collection of programs to convert Standard Midi Files to a textual representation and back. The collection consists of two command line programs, mf2t and t2mf, and a GUI to use these without using the command line.

The command line programs are included in the GUI application distribution, but they can also be downloaded separately if you want to use them directly from the command line, or in scripts. This may be easier than to extract them from the distribution.

History

This is a revival of the programs mf2t and t2mf that I wrote starting in 1991, for the Atari ST (32-bit), MS-DOS (16-bit) and later Unix (probably 32-bits).

I picked this up again in 2023 after some people asked me for executables for modern Windows (presumably 32- or 64-bit). I use a Mac, so I also needed newer versions, for 64-bit macOS (in that time MacOS Ventura).

Modern C-compilers are much more picky than the Kernighan & Ritchie C-compilers that I first used. So the source code had to be adjusted to conform to more modern C standards (in this case C23). The bulk of this work had been done (as far as I know) by Mats Peterson (see below).

I also found a number of changed versions by different people on the Internet, mainly for compiling on Windows 32-bit (for example Windows-XP, which still runs on Windows 11). I’ll try to mention all people who contributed but some contributions were anonymous.

This repository contains the history of the source code as far as possible but, for example, the Original RCS repository for the source code has been lost, so the history is a crude approximation.

All the text files have been converted to Unix format, using UTF-8 when ASCII isn’t sufficient. If you need a Windows or other format, please convert them yourselves.

In 2026 I added a Graphical User Interface (GUI), written in Free Pascal.
